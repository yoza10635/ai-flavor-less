# ai-flavor-less

**中文文本的统计型「AI 味」自查工具** —— 不靠 LLM 判断，用可复现的数值指纹定位自己稿子里的
行文重复与模板化痕迹，并给出**以你自己的稿子为基线**的阈值。

> 定位：**给中文作者的自查校准器**（find & fix AI-flavor in your own draft）。
> 不是「AI 检测器」——请勿用于评判他人作品，原因见下[能力边界](#能力边界)。

## 为什么做这个

市面检测器用**群体绝对阈值**打分，对非母语者、正式文体、以及中文文本系统性误伤
（把《滕王阁序》判成 AI 生成一类的案例屡见报端）。本项目的不同：

1. **作者级相对基线**：用你自己已通过的章节跑 `--calibrate`（均值±2σ）生成阈值，
   检测的是"偏离你自己的常态"，而不是"偏离某个群体平均"；
2. **合取判据**：只有多个相互独立的统计维度同时超标才升级提示，任何单一指标都不定罪
   （全部单指标都实测存在随创作时间漂移的问题）；
3. **实证自否**：每个被否决的方案都留下证伪档案（`references/`），负面清单随证据增长。

方法论的完整定义（定义、成因假说、判据、负面清单、修订四问）见宪章
[ONTOLOGY.md](ONTOLOGY.md)——对本仓库任何实现的增删改都必须先与之对齐。

## 快速开始

```bash
pip install jieba jinja2 pyyaml

# 1. 单章检测（通用 profile）
python scripts/check.py 章节.md

# 2. 网文 profile（叠加创作规范规则：违禁词/情绪直写/对话标签/系统数据行等）
python scripts/check.py --profile=网文 章节1.md 章节2.md ...

# 3. 跨章装置报告（指标①：结尾段复用同一套收尾装置，定位型，AUC 0.718）
python scripts/check.py --cross-chapter ch*.md

# 4. 用已通过的基线章节校准阈值（均值±2σ，人工确认后写入 profiles.yaml）
python scripts/check.py --calibrate 已通过章节1.md 已通过章节2.md ...
```

支持 `.md` / `.txt` / `.docx`；报告输出到 `reports/`，多章时附汇总对比表。

## 方法概览

判据 = **①出现频率 + ②标准化方差 的 2/2 合取**（1/2 提示、2/2 关注）：

| 指标 | 操作化 | 实测 |
|---|---|---|
| ① 出现频率 | 章内：POS 骨架倒排重复簇；跨章：结尾段字符 4-gram 复用（DF≥3 提示/≥5 flag） | 命中已知装置 AUC 0.718 |
| ② 标准化方差 | 章级句长 CV = σ/mean（方向自定：高 → 关注） | 抗漂移 r=−0.081，AUC 0.706 |
| ③ 信息密度 | **已退役**：句对级操作化证伪（盲判精确率 7.5%）——现象保留为开放项 | 见证伪档案 |

辅助层（提示性质，不进判据）：L0 句内结构（可读性）、L0.5 模板标点、L1 词层、
L1.5 规范清单（时敏层，仅特定 profile 启用）。

## 能力边界

- **适用范围 = 中文现代散文体**（小说/散文/报告/说明文）。**诗歌与文言/半文言不适用**：
  句长恒定、对仗复现、重韵律是那些体裁的形式本体（近体诗的 CV 恒低、对仗会触发
  骨架重复 flag）——会被系统性误判，属体裁属性而非 AI 味（宪章 §一/§五-5）；
- 检测对象是**当前 LLM 的写作缺陷**（模板化、句式复现、节奏漂移），随模型迭代会失效，
  其中 L1.5 规范清单属于明确标注的时敏层；
- 统计信号是手段，**读者感知才是目的**：flags 多 = 疑似，不是定论；
- 单作者纵向语料无法干净分离「AI 味累积」与「作者自然风格漂移」——同章节重写对照
  是唯一能同时控制位置+时间+作者的验证设计；
- 检测到的不等于可感知的全部：存在"读不出哪里怪、但读完记不住"的质感缺口，统计无代理
  （宪章 §5-4），这类问题只能靠人工核查。
