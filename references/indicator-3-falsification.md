# 指标③「信息密度」操作化证伪档案

> **结论**：「车轱辘话/信息密度低」作为**章级阅读体验**在本语料真实存在（聚合数据支持），
> 但**任何相邻句对级统计指标都测不到它**——真阳性与正常话题链在句对粒度结构上不可分。
> 2026-09-15 经 40 对盲判复核退役，③降级为开放项（ONTOLOGY §3.4），合取判据改 ①+② 2/2 制。
> 本文档保留完整证据链，是宪章「实证自否」传统的样例。
>
> 检验口径 = 章级 A(A≤ch010，已去味) vs C(C≥ch067，未处理) 分离 AUC + 指标×章号漂移 r。
> 复现：双型实现见 git 历史（v1.2，`l4_density`）；本仓库不再保留代码。

## 1. 操作化设计（2×2 象限）

「新鲜度低 = 车轱辘话 = 换了词没推进内容」。纯统计下从两个可测侧面逼近：
**词汇新颖度**（实词 Jaccard）×**句法新颖度**（POS 骨架编辑相似度）。

| 型 | 判据（段内相邻 ±2 句，长度比≥0.5，实词≥3） | 语义 |
|---|---|---|
| 对偶 para | `jac ≤ 0.25 且 psim ≥ 0.70` | 换词不换句式 |
| 重叠 echo | `jac ≥ 0.20` | 同词复读 |

初版假设把 para 定为车轱辘话主捕捉区——**后被复核证伪为象限方向反了**（§4），
但最终裁决认定粒度错误比象限错误更根本（§5）。

参数网格（30 点）的两条底线教训：
1. **碎片句代理陷阱**：实词下限 <3 时「para」实为短句堆叠代理（漂移 +0.52、方向反转）——`min_content≥3` 是硬底线；
2. ≥4 时信号饿死（检出个位数，量化噪声主导）——`min_content=3` 是工作点。**定底线，不选优。**

## 2. 验收数据（章级速率，对/千字）

| 形态 | A 均值 | C 均值 | 漂移 r | 章级 AUC(C>A) |
|---|---|---|---|---|
| 对偶 para | 0.274 | 0.510 | +0.151 ✅ | 0.690 |
| 重叠 echo | 0.740 | 1.712 | +0.301 ❌压线 | 0.860 |
| 双型并集 | 1.014 | 2.067 | +0.304 ❌ | 0.770 |

参照：指标① 0.718★ / 指标② 0.706★（章对级命中已知装置任务）。核心张力：两型**判别力与抗漂移互反**，无一型双通过。

方法论副产物：**同一指标换任务口径会变脸**——章 CV 在「已知装置命中」章对级任务 AUC 0.706，
在「章级 A vs C」任务仅 0.41（反向）。验收必须预先固定口径。

## 3. 盲判复核（晋级条件 1，40 对）

**协议**：主判定一律盲判（只看句对不回原文——若允许语境，作者意图会为句子辩护，
测的就不是读者表面感知，宪章 Q1）；仅「无法裁决」行可翻回原文改判并标记。
过线标准：**A 组误报 <20% 且 C 组确认率 ≥70%**。抽样 A/C 各 20 对、型内 1:1 分层（seed=20260915；
全量基数 A para=8/echo=21，C para=9/echo=26，A 组 para 不足由 echo 补）。

**结果：全面未达标。**

| 标准 | 要求 | 实测 |
|---|---|---|
| A 组误报率 | <20% | **90%**（17 正常修辞 + 1 无法裁决 + 2 车轱辘话） |
| C 组确认率 | ≥70% | **5%**（1/20；宽算 30%） |
| 总体精确率 | — | **3/40 = 7.5%** |

分型死因：
- **对偶型 A 8/8 全误报 + C 0/9 零确认——测错了对象**。「换词不换句式」的统计签名恰是
  **并列蒙太奇/枚举修辞**的签名（"萧嫣切了萝卜。/陈序洗了排骨。"）。真车轱辘话全部是
  「同词复述」或「后句包含前句」，都落在重叠型定义域。
  复核中另立第四类目「句式重复」（5 行，全在 C 组：同框架换实词×章内相邻）——它本质是
  **L2 骨架聚类的章内近亲**，归指标①域；对偶型检出的全部有效信息都落在这个类目里，
  即对偶型作为③是**零增量**。
- **重叠型抓对了形态但淹没在话题链**：3 个真阳性全出自它，但 C 全量 26 对仅 1 真。
  相邻句共用话题词是对话/连续动作场景的文体属性（宪章 Q3 担忧证实）；
  echo 的高 AUC 实为「后期章节更短促、爱写连续动作」的漂移混淆。
- **翻转豁免 0 使用**，但 3 个「无法裁决」的批注全部依赖**指称同一性/篇章位置**
  （"如果两句连续""如果同一件事""如果同一棵树"）——语篇层事实，段落上下文也救不了。

40 对原始数据见文末附录。

## 4. 镜像象限修正实验（rephrase）

复核后假说：真车轱辘话 = 「换句式不换词」（同词复述展开）——para 象限的镜像。
操作化 `jac ≥ 0.20 且 psim ≤ 上限`：

| psim 上限 | 漂移 r | 章级 AUC | 3 真值捕获 |
|---|---|---|---|
| 0.45 | +0.161 ✅ | 0.620 | 2/3 |
| **0.55** | +0.215 ✅ | 0.640 | **3/3** |
| 0.65 | +0.236 ✅ | 0.670 | 3/3 |

**象限确实反了**（3 真值全捕获、漂移过线），**但作为指标仍不可用**：
1. 量饿死：C 组 10 章全量仅 17 对（A 组 18 对几乎等量）——真车轱辘话本来就稀少；
2. AUC 0.64 低于 ①0.718/②0.706；
3. **探针决定性**：「萧嫣站起来收碗。/叶瑶也站起来。」（盲判为正常修辞）与真阳性
  「一直在擦丹炉——因为没有九转灵藤。/擦丹炉是她能做的唯一的事。」在 rephrase 型中
  **结构不可区分**（jac/sim 同档位：0.40/0.40 vs 0.30/0.45）。

## 5. 最终裁决

**根本问题不是象限选错，是粒度选错。**「两句是否表达同一命题」是语篇层事实
（需指称消解与预设理解），相邻句对在统计上不存在车轱辘话签名。para 零命中不是 bug，
是这个真理的显形：换词通常意味着新事件。

处置（对应 ONTOLOGY §3.2/§3.4）：
- 双型实现从全部报告/汇总/校准路径摘除（代码留存 git 历史 v1.2，复现实验从该提交检出）；
- 宪章合取改 **①+② 2/2 制**，重算（76 章，中位数超标线）：0/2=24 章含 A 组 7、1/2=28、
  **2/2=24 章、A 组 0 章（二项下尾 p=0.034 显著）**；①×② r=+0.116 独立性保持——
  合取核心论断在两指标制下存活；C 组富集 p=0.20 不显著，如实记录；
- 负面清单 +1：**相邻句对级信息密度指标**；
- 未来若重启③，操作化必须 ≥段落级粒度（如话题单元内无新增命题的字数占比），并重过全部三关。

## 6. 方法遗产

- 「先诊断后判定、定底线不选优」的参数扫描纪律沿用自向量密度证伪（`vector-density-feasibility-test.md`）；
- 聚合级信号 ≠ 句对级可定位——本案是「定位型 vs 评分型分工」（ONTOLOGY §六）的镜像案例；
- 镜像假说的处理流程（先验证、再探针、后裁决）为后续证伪提供了模板。
