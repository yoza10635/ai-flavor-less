## 0. 结论速览

1. **lmscan 在中文网文上实测完全失效**，且是**双层失效**：①英文分词/分句假设 → 中文整章被认成 1 句；
   ②即便修复切分，其信号权重的 ~45% 挂在英文词汇列表上，中文全为 0 → C 组（短语云已确认装置复用 5.2/章的未处理章）
   全部判 Human-written（p≈0.000，唯 ch076 得 0.343，且驱动项恰是唯一语言中性的 long_ngram_repetition）。
2. **它的两个节奏特征本来就是 CV**（burstiness=复杂度变异系数，sentence_length_variance=句长变异系数）——
   **反向印证了我们宪章「σ→CV」改造的正确性**，实现可直接参考。
3. **它的长 n-gram 重复（4/5-gram）与我们的指标①同族**，但只做章内；修好切分后实测在章级有分离度
   （A≤0.016 vs C 0.013–0.042）。**这是最值得移植的一个**：保留其算法骨架，作用域升级为跨章（`--cross-chapter`）。
4. 它的裁决架构（加性加权 + 群体绝对阈值 + 词汇表主导权重）**系统性违反**我们宪章的三条核心
   （合取判据 / 作者级基线 / 词汇清单只作时敏提示）——这正是 2025 中文学界批评的误伤机制的开源复刻。
   **借算法，不借管线。**

## 1. lmscan 架构总览（源码事实，非 README 宣传）

三套打分系统 ensemble（scanner.py / detector.py / classifier.py）：

| 系统 | 内容 | 备注 |
|---|---|---|
| 信号检测器 | 21 个带权信号，各做 `sigmoid((value-thr)/thr)` 后**加性加权平均** | 权重合计≈1.22；chatbot 0.13、slop 0.10 为最大单项 |
| 逻辑回归分类器 | 24 特征 z-score 标准化 + L2 LR + Platt/isotonic 校准 | 声称 5000 样本训练 acc 0.927/AUC 0.971；**v0.5/v0.6 权重的源码注释写着 "estimated"——手调** |
| 字符三元组困惑度 | 内嵌 18KB ASCII 字符 trigram 模型（2M 英文字符训练） | ≥100 词时占最终分 20%。**词表为 ASCII+标点，中文全部落 <UNK> logp=-7.5** |

特征层 24 个（features.py，763 行，零依赖 stdlib）。逐特征审计见 §3。

## 2. 中文失效实测（lmscan_cn_test.py / lmscan_cn_test2.py）

### 2.1 第一层：切分失效（原样直跑）

| 输入 | verdict | p | sent | wc | slop | chat |
|---|---|---|---|---|---|---|
| 中文 A 组 ch001–009 | Human-written | 0.000–0.077 | **1–2** | =字符数 | 0 | 0 |
| 中文 C 组 ch067–076（重灾区） | Human-written | 0.000–0.076 | **1** | =字符数 | 0 | 0 |
| EN-AI（README 示例） | **Likely AI** | **0.720** | 5 | 77 | 0.208 | 0 |
| EN-Human | Human-written | 0.112 | 9 | 78 | 0 | 0 |

原因：`_split_sentences` 只认 `[.!?]`，中文 `。！？` 不触发 → 整章 1 句 → burstiness/CV 直接 return 0；
`_tokenize` 按空格切 → 每个汉字成为一个"词" → 词级统计（entropy/hapax/zipf/TTR）语义全变；
英文词表信号（slop/chatbot/transition/hedging/conjunction/contraction）恒 0。
**注意：这不是"中文被判人写"，而是"中文根本没被检测"——flags 面板甚至给出反向噪声
（"Very low burstiness (0.00)" 把分词失败当 AI 特征）。**

### 2.2 第二层：特征失效（修复切分后：。→.、每汉字加空格、？→.）

| 组 | 章 | p | burst | slCV | zipf | bigrep | ngram4-5 |
|---|---|---|---|---|---|---|---|
| A | ch001/002/003/006/009 | 全 0.000 | .213–.253 | .56–.68 | .035–.055 | .13–.17 | .009–.016 |
| C | ch067/070/072/075 | 全 0.000 | .257–.308 | .64–.71 | .062–.082 | .15–.19 | .012–.034 |
| C | **ch076** | **0.343** | .292 | .732 | .076 | **.239** | **.042** |

三点判读：

1. **切分修复救不回来**：C 组仍全部判 Human。因为其大权重信号（chatbot 0.13 + slop 0.10 + transition 0.06
   + hedging 0.05 + conj 0.04 + contraction 0.03 + first_person 0.02 + question 0.02 + list 0.04 + passive 0.05
   ≈ 0.54 / 1.22 ≈ **44% 权重**）在中文小说上恒为 0 或无意义，而"人类信号"侧（burst>0.20 等）中文自然满足 → 净分≈0。
2. **唯一活下来并给出分离的是长 n-gram 重复**：ch072=0.0344、ch076=0.0423，是 A 组最大值（0.016）的 2–2.6 倍；
   ch076 的 0.343 主要由它 + bigram 重复驱动。**它恰好是 lmscan 全部 24 特征中少数不依赖英文词汇的一个——
   而它对应我们的指标①。** 这是"三指标框架跨实现收敛"的独立证据。
3. **CV 方向必须自定**：lmscan 假定"低 CV→AI"（英文说明文节奏均匀）；我们中文网文实测
   **高 CV→C 组**（A 0.660 → C 0.704，命中率 AUC 0.706）。同一指标在不同语料方向相反，
   印证宪章 §五-2「跨语料/跨体裁搬运阈值曾致 6/10 维度方向相反」——**阈值与符号只能 --calibrate 自定**。

局限声明（诚实标注）：字级修复后 entropy/zipf/hapax 是**字粒度**统计，与英文词粒度不可比，
其数值不进入任何结论；本实验证明的是"判决失效"这一负结果，不涉及这些词级特征在中文的应然表现。

## 3. 24 特征逐项审计（四问标尺 + 三指标归位）

处置分四档：**✅ 直接参考 / 🔧 改造后采用 / ❌ 不采用 / ⚠️ 语料自定**。

### 3.1 词汇清单类 —— 全部 ❌（进主判据）

| 特征 | 内容 | 四问判词 |
|---|---|---|
| slop_word_score (w=0.10) | 54 个英文 AI 词（delve/tapestry/…） | Q1 读者可感知✅（对英文读者）；Q2 归因目的性导向❌——这些词特异于**特定模型的训练分布**，非目的性写作的必然产物；Q3 定向惩罚✅命中——爱用 "comprehensive" 的人类作者被误伤。**即我们 L1.5 的英文版**，宪章已判：时敏、公开即失效、只作提示。 |
| chatbot_marker_score (w=0.13，最大单项) | 43 条助手话术（"I'd be happy to"） | 测的是**客服语域**不是叙事文本。对话体小说天然含"let me explain / here's the"。虚构体裁不适用。 |
| transition_word_ratio / hedging_density / conjunction_start_ratio | 英文连接词/对冲短语列表 | 同 L1.5 同构；且英文说明文假设——"Furthermore, 开头"在中文里对应"此外/值得注意的是"，学术文体特征，网文罕见。 |
| contraction_rate / first_person_ratio / question_ratio (负权重=人类信号) | 缩写、第一人称、问句 | 中文无撇号缩写；网文以第三人称为主 → first_person≈0 属**体裁属性**而非 AI 属性，若照搬其"低→AI"方向会**系统性判罚第三人称叙事**。宪章 Q3 一票否决。 |
| list_pattern_density | 项目符号/序号密度 | 对论文有用，对小说无意义（小说无 bullet）。 |

**唯一可借鉴的姿势**：它证明"清单法"对**未改写的聊天输出**（其 9-AI 样本基准）极准——
即清单在"分布内、零编辑"条件下有效，这与我们 L1.5「只作提示、不进合取」的降级结论不冲突，
反而精确了它的**适用边界：问答式 AI 输出，而非创作改写后的文本**。

### 3.2 节奏/统计类 —— ✅/🔧 的主战场

| 特征 | 其算法 | 审计 | 处置 |
|---|---|---|---|
| **sentence_length_variance** (w=0.07) | **CV(句长)** = std/mean | 与宪章指标②**完全同型**——lmscan 一开始就是 CV，反向印证我们 L3 σ→CV 改造；实测漂移 r=-0.081、命中 0.706★ | ✅ **移植实现**（约 10 行，Apache-2.0 注明来源）＋⚠️ 符号自定 |
| **burstiness** (w=0.12) | **CV(每句复杂度)**，复杂度=(unique/total)·ln(1+total) | 比"句长 CV"更信息丰富的节奏指标（把用词多样性折进长度）。我们未测过 | 🔧 **新增 L3b 试验项**：先在 76 章跑漂移检验（×章号 r<0.30 才有资格进合取） |
| **long_ngram_repetition** (w=0.03) | 章内 4/5-gram 重复占比 | **指标①的章内弱版**。§2.2 实测唯一存活特征。权重仅 0.03 被埋没 | 🔧 **核心移植对象**：算法骨架照搬（Counter+>1 计数），作用域升为**跨章**（`--cross-chapter`），章内版并入指标① |
| bigram/trigram_repetition (w=0.03) | 同上，n=2/3 | n=2/3 在中文退化为主谓宾常用搭配噪声（"他的""一个"）；我们已定 n=4 起 | ❌ 低 n 版；由 n=4 跨章版覆盖 |
| char_entropy / punctuation_entropy / entropy (w=0.03) | 香农熵 | Q1：读者感知不到"标点熵低"；Q2：熵是文体通用属性不特异 | ❌（L0 同判：可读性/风格轴，非 AI 味轴） |
| vocabulary_richness (Yule's K) / hapax / zipf_deviation | 词汇多样性/幂律偏离 | TTR/hapax 类已被我们实测否定（命中 0.49，纯漂移，宪章 §四负面清单）；Yule K 比 TTR 抗篇幅，zipf 未测 | ❌ 不进合取。Yule K 可作 L1 辅助展示（比 TTR 略优），zipf 明确不做——**读者无法感知 Zipf 偏离，Q1 直接出局** |
| readability_consistency (FK 段落σ) | Flesch-Kincaid | FK 依赖音节计数，中文音节≈字长，公式失效；且属可读性轴（L0 同类） | ❌ |
| lexical_density (实义词占比) | 功能词表 | 概念=信息密度家族（指标③近亲），但需换中文功能词表（我们有 198 虚词白名单）且方向未验证 | 🔧 低优先：先跑漂移+命中检验再决定，别按英文方向（低→AI）预设符号 |
| passive_voice_ratio | 英文形态学正则 | 中文无动词形态变化，"被"字句统计不等价 | ❌ |
| sentence_opening_diversity (w=0.04) | 句首二元组唯一率 | **指标①的另一种切面**（开头句式复现）；中文网文"他/她/名字+动词"开头天然重复 | 🔧 中文版＝句首词性骨架 2-gram 跨章复现，并入指标①家族，不单设 |

### 3.3 管线类（非特征但一并审）

| 组件 | 审计 |
|---|---|
| **字符 trigram 困惑度**（≥100 词占 20% 权重） | 词表纯 ASCII → 中文全 OOV（-7.5/字）→ 困惑度是常数噪声。语言绑定死的。**语言中性替代=我们的 zlib 压缩率（指标③）**，lmscan 没做，我们反而领先。 |
| **加性加权 Σwᵢsigmoid → 单一 ai_probability** | 宪章正面冲突：单项（尤其词汇表命中）可拉爆总分——chatbot 0.13 意味着一句 "I hope this helps" 就是 +0.13/1.22 的直接 AI 分。我们的合取判据（1/3提示、2/3关注、3/3疑似）就是为了杜绝"单指标定罪"。**不采用其打分架构。** |
| **群体 μ/σ 标准化 + 绝对阈值** | 即 GPTZero 的群体基线误伤机制（ESL>60% FP）的开源复刻。其 calibration API 只做**全局阈值搜索**（find_optimal_threshold 扫 0.3–0.8），**没有 per-author 基线**——宪章第七节方向在它那里不存在。 |
| **12 样本基准（9 AI+3 人类）** | "67%→100%"的提升来自**添加那 43 条模型恰好爱说的话术**——先列清单再测清单，宪章 §3.3 禁止的"先假设后验证"的教科书案例。无对称实验（改结构留文体），未过宪章 §一 采纳判据。 |

## 4. 审计总账

| 档位 | 特征 | 数量 |
|---|---|---|
| ✅ 直接参考 | sentence_length_variance(CV)、long_ngram_repetition(算法骨架) | 2 |
| 🔧 改造后采用 | burstiness(复杂度CV→L3b 试验)、lexical_density(换表+验方向)、sentence_opening_diversity(并入①)、punctuation_entropy(重定义为中文标点规范度→L0.5 族) | 4 |
| ⚠️ 符号/阈值必须自定 | 上述全部（§2.2 CV 方向已证反） | — |
| ❌ 不采用 | 10 个词汇/语域清单、3 个英文词级统计、entropy×2、zipf、FK、passive、低 n-gram、困惑度模型、加性打分架构、群体阈值、12-sample 基准法 | 18 项 + 架构 |

**通过率 6/24**，且通过的恰好是我们三指标的映射位（②CV 印证、①n-gram 移植、L3b 增量），
被否的全在词汇清单与英文管线——**lmscan 的价值不在"它的检测器"，在"它的两个公式"和"它的失效模式"**。

## 5. 落地行动（映射回 Skill 待办，优先级已按本审计更新）

1. **P0 · `--cross-chapter` 4-gram 短语云（指标①）** —— 不变，仍是最高优先级；
   实现时参考 lmscan `long_ngram_repetition` 的 Counter 骨架（加源码注释：`# algorithm adapted from lmscan (Apache-2.0), scope widened to cross-chapter`），
   同时新增**章内版**作为其单章退化。
2. **P0.5 · L3 σ→CV** —— 直接照 lmscan `sentence_length_variance` 的算法（std/mean，逐句词长），
   省一半设计时间。符号按我们语料（高→关注）自定，不继承其 low_is_ai。
3. **P1 · 新增 L3b 试验位：复杂度 CV**（unique/total·ln(1+n) 的变异系数）——
   先跑 ×章号漂移检验，r<0.30 才提名进指标②家族；否则进负面清单。
4. **P2 · 句首多样性中文版** 并入指标①（POS 骨架跨章复现），单章版并入 L2。
5. **不做**：困惑度、FK、passive、zipf、一切手工词表扩充。
6. **合规**：Apache-2.0 允许移植实现，需在 derived 文件头保留版权声明 + 变更说明（NOTICE 段落）；
   不复制其数据文件（词表、trigram 模型）——反正也用不上。

## 6. 对开源定位的增量意义

- lmscan 的存在**坐实了宪章 §四负面清单的普适性**：它用 24 特征堆出来的分数，在中文创作语料上的判别力
  不如我们的 2 个指标（跨章 4-gram 0.718★、CV 0.706★）——"更多特征≠更强检测"是开源叙事里现成的对照案例。
- 方法论/代码两阶段开源策略不变，且新增一个可发布的实证工件：**"lmscan-on-Chinese：一个开源统计检测器
  的双层失效解剖"**，这类竞品证伪文在开发者社区传播力极强，也天然把我们定位在"方法论权威"一侧。
