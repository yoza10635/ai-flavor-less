# StoryScope 候选维度迁移测试（中文网文语料）

> 测试日期：2026-09-15
> 语料：`Project/novel-create/05-正文` 全 76 章
> 分组：**A = ch001-010（已去 AI 味）** / **B = ch011-066** / **C = ch067-076（未处理·AI 味重）**
> 方法：把 StoryScope 的 30 个核心特征中"理论上可用词表近似"的部分做成语义场词表，测三组密度（次/千字），算 Cohen's d

---

## 0. 一句话结论

**StoryScope 给的是「维度清单」，不是「方向」和「阈值」。**

10 个候选维度里：8 个在你的语料上**可测**，但**方向只有 3 条与论文一致，6 条相反，1 条完全无效**。
→ 维度可以照抄，**符号与阈值必须用自己的基线校准**（`--calibrate` 本来就是干这个的）。

---

## 2. 三条最值得记的

### 2.1 论文里判别力最强的那条，在你这里完全失效

`Direct Reader Address` 是 StoryScope 里 **4 倍差异**（人类 28% vs AI 7%）的特征，我原本判断它是"最该先加"的维度。
实测：**A 组 0.00、C 组 0.00，Cohen's d = 0.00——全书 76 章几乎不出现。**

原因：中文网文（尤其第三人称修仙）**根本不称呼读者**。这是**体裁属性**，不是 AI 属性。
→ 论文的特征排序**不能直接当优先级**，必须过一遍语料存活检验。

### 2.2 判别力最强的一条，方向是反的

`嗅觉` d = +1.44 是全部维度里最强的（A 组 0.93 vs C 组 0.05，**18 倍**），但方向与论文相反：
论文说 AI 更爱写嗅觉（82% vs 57%），你的语料里**已去味的章节嗅觉词密度反而高 18 倍**。

这说明两件事：
1. **维度本身有价值**（它是这里判别力最强的语义场指标）——只是**符号要反着用**。
2. **存在密度混淆**：C 组是短句稀疏体（σ 4.37），描写总量本来就少，所有"密度类"指标都会被系统性压低。
   反证：因果连接（虚词，不受描写稀疏影响）确实是 C 组更高（0.35 vs 0.17），与论文一致。
   → 所以**不能把所有反转都归因为"密度混淆"**，但**也不能全信**——必须逐条验证。

### 2.3 你的创作规范与论文在一处直接冲突

`04-创作规范/AI痕迹检查清单.md` 第 4 条：
> 情绪用行为体现，不直接命名（如"他感到愤怒"→"他的手指握紧了剑柄"）

这正是 StoryScope 说的 **embodied**（论文：AI 81% vs 人类 38%）。
而实测你的语料：**A 组身体化 0.57 > C 组 0.38**，同样与论文相反。

→ 我倾向认为**你的规范在中文网文语境下是对的**（"show don't tell" 是硬功夫），
   但这说明**不能用论文裁决你的规则**，也不能用论文裁决我的维度符号。
→ 现行 `EMO_PAT`（情绪直写判 AI 味）在这语料上 **0 命中**，属死规则，与这条冲突一起复核。

## 3. 因此：StoryScope 的增量价值到底在哪

| 层面 | 是否转移 | 说明 |
| --- | --- | --- |
| **维度清单**（该测什么） | ✅ **转移** | 你的六层全是**形式层**（字/词/句/节奏），缺**语义场层**——读者介入、互文、感官、时间、主题、因果。这是真实的空白。 |
| **可测性**（能不能用纯统计测） | ✅ **大体转移** | 10 条里 8 条能用词表测，无需 LLM。 |
| **方向 / 符号** | ❌ **不转移**（3/10） | 必须用 `--calibrate` 在自有基线上定符号。 |
| **阈值** | ❌ **完全不转移** | 英文文学短篇的分布与中文网文不可比。 |
| **优先级** | ❌ **不转移** | 论文最强的一条在你这里完全无效。 |
| **跨章维度** | ❌ **论文没有** | 见下。 |

## 4. 论文给不了、但你的语料给了的维度

StoryScope 是**单篇分析**，304 个特征全部在单篇内计算，**没有跨文本维度**。
而本语料实测判别力最强的是跨章指标：

| 维度 | A | C | 判别力 |
| --- | --- | --- | --- |
| **跨章结尾装置复用**（末 3 段 6-gram 跨章计数） | **0.0** | **5.2** | **近乎完美分离**（8/10 章涉，A 组零） |

这**远超**上表任何一条 StoryScope 派生维度（最强 d=1.44，且方向还需反转）。

→ **结论：论文给出的是"单篇语义场"这一层；真正的高判别力维度在"跨章结构"这一层，论文里根本没有。**

## 5. 落地建议（按此顺序）

### 第一步：新增 L4 语义场层，但**不预置方向**

把下面这些做成**只报数值、不判 flag** 的观测项，先跑一遍全书看分布：

| 语义场 | 词表要点 |
| --- | --- |
| 感官 | 嗅觉（香/气味/腥/焦/臭/闻到/药香）、触觉（发凉/发紧/粗糙）、味觉 |
| 身体化 | 胸/喉/心口/指节/手心/攥/抿 |
| 情绪标签 | 愤怒/悲伤/恐惧/喜悦/害怕/难过 |
| 时间 | 想起/当年/多年前/那时/回忆/从前 |
| 主题 | 抽象名词（命运/人性/意义/真相/代价）× 判断动词（终究是/不过是/在于） |
| 因果 | 因为/所以/于是/因此/导致 |
| 互文 | 《》具名 vs 某本/据说/传说 泛指 |

然后用 `--calibrate` 在 ch002/ch003/ch006（现有基线）上定**符号与阈值**。

### 第二步：**优先做跨章维度**（判别力最高、论文没有）

- 跨章结尾装置复用（`--cross-chapter`）
- 跨章道具/场景复用
- 跨章 σ 漂移（本次实测 σ 从 7.47 单调降到 4.37，是全书最稳定的信号）

### 第三步：退役/复核

- `EMO_PAT`（0 命中，且方向与论文冲突）
- `BAN_WORDS`（0 命中）
- `stack_thresh=7.5`（**反向**：A 组 10% vs C 组 0%）
- 读者介入维度**不要做**（语料上完全无信号）
