# 跨章检测：短语云（n-gram cloud）方法

> 验证日期：2026-09-15 · 语料：`Project/novel-create/05-正文` 全 76 章
> 起因：用户提出「跨章节的话感觉倒是可以用词云」——实测后确认思路正确，但需两处修正

---

## 0. 结论

**词云思路成立，但要做成「结尾段 + n-gram 短语云」，不是「全文 + 单词词云」。**

| 方案 | 结果 |
| --- | --- |
| 全文 + 单词词云 | ❌ 被虚词（不是/一个/一下）与人名（萧嫣/陈序）吃掉 |
| 结尾段 + 单词词云 | ❌ 太稀疏，160 字窗口内 DF 上不去 |
| **结尾段 + 4-gram 短语云** | ✅ **有效**，零假设自动挖出 20 个跨章复用装置 |

---

## 1. 为什么单词级不行（一个负结果，但很重要）

对全文做「文档频率 DF + 跨章变异系数 CV」排序，top 全是：

```
萧嫣(73章) 陈序(73章) 不是(72章) 一个(70章) 一下(67章) 什么(65章) 看着(65章) ...
```

→ **DF 高只说明"每章都出现"，等于内容常量，不是模板。**
→ 单词级无法区分「故事本来就有这个人/这个东西」和「作者写顺手了」。

另一个负结果：**A 组 vs C 组的单词级对数优势比（log-odds）被内容严重混淆**。
挖出的判别词是 `叶瑶(z=-9.07)`、`萧嫣`、`本子`、`碧螺春`、`井台`、`丹房`、`西屋`——
这些是 C 组的**题材**（院落日常章、后期加入的角色），不是 AI 味。
反向则是 `孙守`、`弟子`、`长老`、`灵力`、`灵气`、`废人`——A 组的**题材**（宗门/收徒前期）。

→ **单词承载着内容；内容差异淹没文风差异。单词级自下而上挖掘不适用于"AI 味词典"。**

## 2. 短语云方法（可用）

### 2.1 规格

| 参数 | 值 | 理由 |
| --- | --- | --- |
| **抽取范围** | 每章**最后 3 段** | 收尾装置集中在结尾；全文会被内容与虚词稀释 |
| **切分** | 去全部非汉字后，字符 n-gram | 不需要分词，不受分词错误影响 |
| **n** | **4** | 4-gram 得 20 个跨章片段，粒度刚好；5-gram 降到 8 个、6-gram 只剩 3 个，太稀疏 |
| **阈值** | 出现在 **≥3 章** | 少于 3 章视为偶发 |
| **输出** | 片段 × 章号列表 | 直接可核查 |

> 注：**不需要任何词表、不需要语义假设、不需要 LLM。** 完全自下而上。

### 2.2 实测结果（全书 76 章）

**4-gram（20 个跨章片段，取 top10）：**

| 片段 | 章数 | 章号 |
| --- | --- | --- |
| **合上本子** | **×11** | ch8, 9, 20, 23, 41, 53, 60, 63, 70, 71, 72 |
| 萧嫣不知 / 嫣不知道 | ×4 | ch35, 37, 38, 44 |
| 果子掉下 / 子掉下来 | ×4 | ch67, 71, 72, 74 |
| 但她知道 | ×4 | ch37, 38, 45, 52 |
| 他合上本 | ×4 | ch41, 60, 70, 72 |
| 东屋的灯 | ×4 | ch8, 10, 24, 76 |
| 陈序合上 | ×3 | ch23, 53, 63 |
| 视野底部 | ×3 | ch14, 17, 75 |

**5-gram**：萧嫣不知道×4、果子掉下来×4、他合上本子×4、核心在丹田×3、子掉下来嗒×3
**6-gram**：陈序合上本子×3、核心在丹田里×3、果子掉下来嗒×3

## 3. 意外发现：装置有「任期」

跨章片段按章号聚集，呈现明显的**分段簇**：

```
ch008-024   合上本子 / 东屋的灯 / 陈序合上
ch035-052   萧嫣不知道 / 但她知道 / 视野底部
ch067-076   果子掉下来 / 枣树上 / 明天——该收枣了
```

→ **不是"越到后面越模板化"，而是每一段有自己的一套装置**。
   作者咬住一个装置用约 15–20 章，然后换下一个。

**这修正了此前"ch067-076 是重灾区、前面干净"的判断**——
A 组（ch001-010）之所以跨章复用为 0，部分原因是它处于**装置更换的间隙**，
而不是它天然免疫。ch035-052 也有自己的装置簇（×4 级别）。

→ 因此处理优先级应改为：**按装置簇整段处理**，而不是只修末尾 10 章。

## 4. 与语义场方案的关系

| | 语义场（StoryScope 派生） | 短语云（本方案） |
| --- | --- | --- |
| 方法 | **先假设后验证**（top-down） | **自下而上**（bottom-up） |
| 需要外部假设 | 是，且借自异域论文 | **否** |
| 方向/阈值来源 | 论文（实测 6/10 相反） | 无方向概念，只看复现 |
| 内容混淆 | 中（词表是语义的） | **低**（测分布形态，不测词义） |
| 定位 | 单篇内密度 | **跨章结构** |
| 可解释性 | 需解释语义场为何相关 | **直接给片段+章号，可核查** |

→ **短语云正好补上了"先假设后验证"的短板**：它不需要你先猜哪个语义场重要。

---

## 5. 落地建议

1. **先做短语云**（无假设、判别力最高、可解释）。
2. 语义场层若要做，**词表不要用论文的**，改用短语云挖出的片段 + `--calibrate` 定符号。
3. 报告新增一节 `## L5 跨章装置`，输出：片段 / 章数 / 章号列表 / 所属簇。
4. flag 建议：单个 4-gram 出现在 **≥3 章** 即提示；出现在 **≥5 章** 判 flag。
   （全书 76 章下，≥3 章是 4%，属低概率事件）

## 6. 复现

```python
# 结尾段 4-gram 短语云（无依赖，纯标准库）
import glob, re
from collections import Counter, defaultdict
files = sorted(glob.glob('ch*.md'))
df = defaultdict(set)
for f in files:
    ch = int(re.search(r'ch(\d+)', f).group(1))
    t = re.sub(r'^#.*$', '', open(f, encoding='utf-8').read(), flags=re.M)
    ps = [x for x in t.split('\n') if x.strip()]
    s = re.sub(r'[^\u4e00-\u9fff]', '', ''.join(ps[-3:]))
    for g in {s[i:i+4] for i in range(len(s)-3)}:
        df[g].add(ch)
for g, chs in sorted(df.items(), key=lambda x: -len(x[1])):
    if len(chs) >= 3:
        print(f'×{len(chs):2d}  {g}  ch{sorted(chs)}')
```
