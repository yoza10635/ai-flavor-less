# 六层检测原理与报告数据结构

`scripts/check.py` 的逐层原理、判定规则、归因互斥逻辑，以及报告模板各节对应的数据键。修改脚本或阈值前读本文档。

## 总体架构

- **L0/L0.5/L1/L2/L3 为统计核心**：不依赖文体先验，只做文本内相对异常判断（重复度、节奏、信息密度），对论文/网文都成立。
- **L1.5 为文体层**：把项目创作规范（AI 痕迹检查清单）里可自动化的项写成规则，仅在 `banlist: true`（默认网文 profile）时启用。
- **profile 配置项**（内置默认，可被 `profiles.yaml` 覆盖）：

| 键 | 通用 | 网文 | 含义 |
| --- | --- | --- | --- |
| banlist | false | true | 是否跑 L1.5 违禁词/情绪直写/对话标签/数据行 |
| dialog | false | true | 是否判对话标签占比（与 banlist 联动） |
| dataline | false | true | 是否判系统数据行 |
| dash_thresh | null | 4.0 | 破折号绝对阈值（次/千字），null = 只报分布不 flag |
| de_long_flag | false | true | '的'长链 ≥3 是否判 flag（论文天然密度高，通用只展示） |
| tpl_thresh | 5 | 3 | 模板词对命中总数 ≥ 该值判 flag |
| rep_ratio | 0.10 | 0.06 | 重复骨架句占全句比例 > 该值判「句式单调」 |
| de_sto_flag | false | true | 顿号并列"的"是否判 flag（与 banlist 同为文体层开关） |

> 注：文体层 flag（节奏偏匀/破折号/'的'密度/违禁词/情绪直写/对话标签/3-4句段/数据行）统一由 `banlist` 开关控制，不做 profile 名硬编码——自定义 `banlist: true` 的 profile（如"论文加强版"）会完整获得文体层检测。
| sigma_thresh | 4.0 | 4.0 | 段落 σ 均值低于该值判「节奏偏匀」（网文） |
| de_density_thresh | 6 | 6 | '的'密度（%/千字）超该值判 flag（网文） |
| tag_thresh | 0.30 | 0.30 | 对话标签占比超该值判 flag（网文） |
| mid_ratio_thresh | 0.55 | 0.55 | 3-4 句段占比超该值判 flag（网文） |
| stack_thresh | 0 | 0 | 词性堆叠行数 > 该值判 flag |

## L0 句内结构（l_intra）

- **'的'连续链**：POS 为 `uj` 且之间无标点打断即同链。**顿号不断链**（顿号连接的并列修饰语属同一链，切开会漏掉排比定语），因此用 `sto_break=False` 的切分模式。链长 ≥3 = 长定语堆叠（AI 味）；链长 =2 = 可接受，仅展示。
- **归因互斥**：句中若含「'的'字结构 + 顿号」并列（`STO` 前一词是字面"的"，句内 ≥3 处），则视为**标点形态问题**（顿号误用，规范 GB/T 15834 宜用逗号），不再计入长定语 AI 味——两类命中互斥，避免双重归因。
- **'地'状语堆叠**：句内 `uv` ≥2。
- **词性堆叠**：在原始词性序列（含标点标记）上数连续同词性段，标点/助词（uj/ul/uv/uz/ug/u）天然打断，避免"删虚词后假连击"误报；≥3 且末位词性为实词系（v/vn/a/an/ad/n/z/l/i）才报。
- **'是……的'强调句**：要求最后一个"的"位于分句末尾（后面只剩标点/引号/语气词），且"是"与"的"之间有动词短语。仅同句出现不算（如"这是硬科幻给AI的第一副面孔"）。
- **'的'密度**：'的'总数 / 总字数 × 100（即每百字个数），超 `de_density_thresh`（默认 6）判 flag（仅网文）。

数据键：`l0 = {density, de_long:[(段号,链长,的数,句)], de_two, de_sto:[(段号,处数,句)], uv_rows, stack_rows:[(段号,连续数,词性,句)], shi_rows, n_de, n_chars}`

## L0.5 模板标点（l_tpl_punct）

- **模板词对**：20 组标记词（不是…而是 / 不仅…而且 / 既…又 / 虽然…但是 / 一边…一边 / 与其…不如 / 宁可…也不 / 无论…都 / 只要…就 / 因为…所以…等）。在**标点句**（按句号切，避免逗号劈开模板）内 m1 按序出现 m2 即命中，填充任意。同一模板句内多次出现 m1 只要其后存在 m2 也算。命中 ≥2 次进报告，总数 ≥`tpl_thresh` 判 flag。
- **标点密度**：破折号按"组"计（`——` 算一次，单个 `—` 也算，半角 `--` 并入）；省略号按 `…{2,}` 组计；问号/感叹号/分号/冒号按字符计。输出次/千字。破折号 > `dash_thresh` 判 flag（仅网文）。

数据键：`tpl = {tpl_rows:[(模板名,次数,例句list)], punct:{破折号/省略号/问号/感叹号/分号/冒号: 次每千字}, chars}`

## L1 词层（l1_stats）

- **新信息率**：滚动窗口 400 个实词（约 600 字）为记忆，段落新实词（len≥2 的 n/v/a 系）占该段实词比例 <0.12 且该段实词 ≥5（过滤对话碎片段）→ 信息停滞段。
- **句首/句末词分布**：句首跳过引号/停顿/句末符，取第一个实词；句末取最后一个非标点词。Top12 进报告；句末语气助词（了着的过啊呢吧吗呀嘛罢哦嗯唉）占比单列——语气词占比高是口语化/AI 对话体特征。
- **高频 3-gram**：词级，≥3 次进报告 Top40。

数据键：`l1 = {low_info_paras:[(段号,比例,新词数,总实词数)], starts_top, ends_top, end_aux_ratio, grams_top}`

## L1.5 规范清单（l_banlist，仅 banlist=true）

- **违禁词** BAN_WORDS：不禁/忍不住/心中暗道/眼中闪过一抹精光/涌上心头/在当今社会/随着时代的发展/众所周知/总而言之/心中一动。
- **情绪直写** EMO_PAT：`(感到|觉得|心中|心里|心底|一股|涌上|生出|泛起|满心)(?:了)?(?:一阵|一丝|一股|莫名的|的)?(愤怒|悲伤|恐惧|…)`——"情绪名词直写"是 AI 高频模式，规范建议用动作/生理反应呈现。
- **对话标签占比**：引号内容 + 短距离内的 说/道/问/喊/答/笑道/沉声道/淡淡道/轻声道/低声道/开口/嘟囔 等（后置 DIALOG_TAG + 前置 DIALOG_TAG_PRE 两式），占比 = 命中 / 引号数，> `tag_thresh` 判 flag。
- **3-4 句段占比** mid_ratio：段内句数 3-4 的段占比 > `mid_ratio_thresh` 判「段落 3-4 句偏多」（节奏均匀化的另一面）。
- **系统数据行** DATA_LINE：`^[^：:]{1,12}：[^：:]{1,24}$` 且无引号（排除对话引导冒号"萧嫣抬眼："），**连续 ≥2 段**才报（单行冒号句是正常行文）。

数据键：`bl = {ban_hits:[(段号,词,前60字)], emo_hits, tag_ratio, quote_ratio, n_quotes, para_counts, mid_ratio, data_runs:[[段号,…]]}`

## L2 句法层（l2_skeletons）

- **骨架生成**：POS 序列去功能词（uj/ul/uv/uz/ug/u）与停顿标点（COM/STO/PUN），保留实词词性 + EOS/QT 结构锚点，`|` 连接。人名归一化为 PN（normalize_pn=True），让不同人名的同构动作句合并成簇。
- **碎片过滤**：清洗后 token 数 <3 不进簇；3-token 骨架需 ≥4 次、4-token 需 ≥3 次（过滤偶发）；占比 >25% 的泛骨架视为粒度噪声剔除。
- **排比簇**：相邻 ≥3 句骨架完全相同（且句号连续）。
- 重复句占比 = 簇内句数之和 / 全句数，> `rep_ratio` 判 flag。

数据键：`reps=[{skel, n, items:[(句号,句)]（截取前10）, total}], runs=[[(句号,句,骨架)…]]`

## L3 节奏层（l3_rhythm）

- 段内句数 ≥3 才统计。指标：平均句长、σ（句长标准差）、MSSD（句长序列 mean successive difference）、短句占比（≤8 字）。
- σ/MSSD **越高越好**（节奏有起伏）；σ 均值 < `sigma_thresh` 判「节奏偏匀」。校准时高好型阈值 = mean − 2σ，其余 = mean + 2σ。

数据键：`l3 = [{para, n, mean, std, mssd, short}]`

## 汇总 flag（summarize，报告与终端汇总表共用）

flags 生成顺序：重复骨架占比 → 排比簇 → 信息停滞(≥3) → 模板 → 词性堆叠 → '的'长链(≥3，de_long_flag) → 顿号'的'(网文) →（网文）节奏偏匀 / 破折号 / '的'密度 / 违禁词 / 情绪直写 / 对话标签 / 3-4句段 / 数据行。

## 输入格式与切分归一化

- **支持格式**：`.md` / `.txt` / 无扩展名 → `read_text`（utf-8-sig → gbk → latin-1 依次回退）；`.docx` → `read_docx`（标准库 zipfile 解压 `word/document.xml`，按 `<w:p>` 段取 `<w:t>` 文本，仅正文，表格行合并为段，页眉页脚/批注/脚注不计入）。docx 无 `#` 标题，标题回退为去扩展名的文件名。
- `SENT_END = 。！？…`，`CLAUSE_END` 另含 `，、：；`。
- 读入时半角标点归一化：`,`→`，` `!`→`！` `?`→`？` `;`→`；` `:`→`：` `()`→`（）`。
- Markdown：`#` 行取标题不入统计，`>` 引用行、`—*=~` 分隔线跳过。
- `split_semantic_sents(text, sto_break=True)`：语义句（逗号/句末符切；sto_break=False 时顿号不切，供 L0 '的'链用）。
- `split_final_sents(text)`：标点句（仅句末符切），供 L0.5 模板/数据行/L1.5 用。
- TokCache：同一 (句, normalize_pn 模式) 只标注一次，L0/L1/L2 共享。
